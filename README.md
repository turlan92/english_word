# Обновление Telegram-тренажёра

## Установка на Windows

1. Остановите старого бота (Ctrl+C). Сделайте копию папки проекта.
2. Из архива перенесите bot.py, catalog.py и requirements.txt в папку:
   C:\bot_2\phrasal_verbs_bot\phrasal_verbs_bot
3. В этой же папке оставьте свои .env, progress.sqlite3 и
   vasilyeva_phrasal_verbs_pages_4-33.sqlite3. Не заменяйте базы другими версиями.
   В архив базы и токен не включены.
4. В терминале этой папки выполните:

   python -m pip install -r requirements.txt
   python bot.py

5. Отправьте боту /myid. Он покажет ваш Telegram ID.
6. Остановите бота. В существующий .env добавьте строку:

   ADMIN_IDS=ваш_числовой_ID

   Например: ADMIN_IDS=123456789 (замените на свой ID, без кавычек).
   Существующий BOT_TOKEN сохраните. Запустите python bot.py снова.
   Без ADMIN_IDS никто не может импортировать слова или смотреть /users.

Файл .env.example — только образец. Если .env уже есть, не заменяйте его.
Python 3.10 или новее. Запускайте одну копию бота с этим токеном и базами.

## Добавление слов из книги

Создайте Excel-файл .xlsx. На первом листе в строке 1 укажите ровно эти
шесть заголовков, каждый в своей ячейке:

| книга | глава | слово | перевод | пример | перевод примера |
|---|---|---|---|---|---|
| Мой учебник | Глава 1 | look after | заботиться о | I look after my son. | Я забочусь о сыне. |
| Мой учебник | Глава 1 | give up | сдаваться | Don't give up. | Не сдавайся. |

Примеры в таблице составлены для демонстрации, это не цитаты из книги.
Первые четыре поля обязательны. Пример и перевод примера необязательны.
Формулы запрещены: вставляйте текстовые значения. Допускается CSV UTF-8
с такими же заголовками и разделителем «;» или «,».

1. Напишите /import в личном чате бота.
2. Отправьте заполненный Excel как документ.
3. Бот проверит весь файл, затем добавит слова и покажет количество.
4. Откройте /mode и выберите книгу и главу.

Лимиты: 2 МБ, 1000 слов за загрузку. Импорт доступен только ID из ADMIN_IDS.
Каждая пара «книга + глава» — отдельный учебный набор. Названия должны
совпадать точно, иначе получится новый набор.
Повторное слово с тем же переводом внутри набора пропускается (без учёта
регистра и повторных пробелов). Другой перевод создаёт отдельную карточку.
Импорт только добавляет: повторной загрузкой нельзя исправить перевод или пример.
Все импортированные слова доступны всем пользователям.
PDF автоматически не разбирается: слова из книги нужно перенести в таблицу.

## Пользователи и статистика

Каждый пользователь открывает бота по его ссылке и нажимает /start.
Регистрация происходит автоматически по Telegram ID. Имя и время активности
сохраняются в users; индивидуальный прогресс — в progress.sqlite3.
Старый пользователь появится в /users после первого обращения к новой версии.
Обучение работает в личных чатах.

/stats — статистика выбранного набора конкретного пользователя.
/users — администратору: число пользователей и сводка последних 20 активных.
«Начато» — карточки, на которые был хотя бы один ответ.
«Закреплено» — три или более правильных ответа подряд; это условный показатель.

Верные ответы: повторение через 1, 3, 7, 14, 30 дней. После пятого — каждые
30 дней. Ошибка: повтор через 5 минут, серия верных ответов сбрасывается.
Повторения выдаются раньше новых слов и не зависят от дневного лимита.
Лимит новых слов действует отдельно для каждого набора и пользователя.
Бот сам не присылает напоминания: повторение появляется после /learn или кнопки.

## Базы и совместимость

Исходные 551 запись копируются при первом запуске в новую таблицу catalog
в той же базе словаря. ID старых слов остаются прежними; исходные entries,
source_pages, sources и study_progress не удаляются.
Новые слова добавляются в catalog. Старая версия бота их не увидит.
Предыдущий прогресс сохраняется, если оставить прежний progress.sqlite3
и соответствующую ему базу словаря с теми же ID.
Перед миграцией/импортом создаётся резервная копия словаря в backups;
при запуске создаётся копия progress.sqlite3, если файл существует.
Копии не удаляются автоматически; периодически проверяйте размер backups.

## Проверка этой сборки

Проверены на копии предоставленной базы: миграция и сохранение ID,
сохранение старого прогресса, импорт и дубликаты, отказ при ошибочных строках,
разделение прогресса пользователей, интервалы повторений, приоритет повторений,
защита старых кнопок, запрет импорта для обычного пользователя и статистика.
Проверки Telegram-обработчиков выполнены с имитацией отправки сообщений.
Живой запуск с вашим токеном не выполнялся.
